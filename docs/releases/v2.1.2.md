# PS2UI 统一整合包 v2.1.2

本 Release 是 PS2UI 当前公开产物的统一下载入口。各产品仍保留自己的版本号，便于独立升级；本次整合包用同一个 Release 承载全部安装文件。

## 产品版本

- PS2UI Photoshop：2.1.2
- Ps2Unity：2.1.1
- Ps2Godot：0.1.1
- Ps2Cocos：0.1.1
- Ps2Unreal：0.1.1（UE 5.7 / 5.8 Win64）
- PS2UI Engine Installer：0.1.1（Windows 10/11 x64）

## 下载建议

- Windows 用户优先下载 `PS2UI-Engine-Installer-0.1.1.exe`，它可以多选引擎项目并显示安装后的启用教程。
- Photoshop 用户下载 `PS2UI-Photoshop-2.1.2.ccx`，双击安装后重启 Photoshop。
- 需要手动安装时，下载对应引擎 ZIP 或 Unity `.unitypackage` / UPM 包。
- 每个产品都有对应的 `SHA256.txt` 文件，发布页同时提供 GitHub 资产摘要。

## 兼容范围

- Photoshop 2023（24.0）及以上
- Unity 2022.3
- Godot 4.6.2
- Cocos Creator 3.8.5-3.8.8
- Unreal Engine 5.7 / 5.8 Win64
- 安装器：Windows 10/11 x64，项目级安装，无需管理员权限

## 首次导入

先在 Photoshop 中导出包含 `layout.json` 和 `sprites` 的 Package 根目录，再在目标引擎中使用“导入 PS2UI 导出包”。选择 Package 根目录，不要选择 `sprites` 子目录。九宫组件只修改宽高，不要修改 Scale。

详细教程、字体映射、资源复用和故障排查见仓库 [README](../../README.md)。
