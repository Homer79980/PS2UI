# PS2UI v2.1.16 - AI 命名分类切换修复

发布日期：2026-09-21

- 修复 AI 命名结果列表中点击其他分类没有生效的问题。
- 新增“无类型”，可以去掉类型前缀，例如 `Img_BabyStroller_Pink` 变为 `BabyStroller_Pink`。
- “无类型”会在手动编辑、列表刷新、重新应用命名格式和确认写回时保留，也可以再次切换到其他分类。
- 九宫控制标记、重名去重和九宫母图/实例元数据继续保留。
