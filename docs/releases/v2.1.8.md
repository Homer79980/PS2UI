# PS2UI v2.1.8

发布日期：2026-09-16

- 修复 AI 命名完成后点击“确定”没有反应的问题。
- 确认结果按对应图层写回，支持未选中、锁定图层和锁定组内的图层；跳过隐藏图层及隐藏组中的图层。
- 支持背景图层命名：Photoshop 的背景图层会转为普通图层后改名，保留像素内容，并恢复锁定与选择状态。
- 九宫实例采用确认后的名称，并保留资源族关系和尺寸标记。
- 写回后校验实际图层名，失败时回滚并显示原因；名称已经一致时明确提示无需写回。
- 改进 AI 请求限速与重试、面板图层索引和导出过程的状态反馈。

## 安装

下载 `PS2UI-Photoshop-2.1.8.ccx`，双击通过 Creative Cloud 安装，然后重启 Photoshop。面板左上角应显示 `v2.1.8`。支持 Photoshop 2023（24.0）及以上版本。

同一 Release 提供 `PS2UI-2.1.8-SHA256.txt` 用于校验安装包。
