# PS2UI 2.1.21 / Unity 3.2.6：文字定位修复

2026-10-22。支持 Photoshop 2023+ 与 Unity 2022.3。

## 更新内容

- PS2UI 2.1.21：点文字定位使用不含阴影等效果的字形边界；图片导出范围及效果描述保留。
- Unity 3.2.6：点文字按可见字形垂直居中，整页预览与生成的 Prefab 使用相同定位方式；保留原字体、材质映射和段落排版。
- Engine Installer 0.1.4：内置 Unity 3.2.6；Godot、Cocos 和 Unreal 包版本沿用当前已发布版本。
- 保留 2.1.20 的 AI 可见物体命名与取图保护，Package 和字体协议保持兼容。

## 更新方式

1. 安装 Photoshop 插件 `PS2UI-Photoshop-2.1.21.ccx`，重新打开 PS 面板。
2. 安装 Unity 3.2.6，或使用 Engine Installer 0.1.4 更新安装器管理的 Unity 插件。安装前保存并关闭引擎编辑器。
3. 用新版 PS 插件重新导出原 PSD/PSB，再导入 Unity。

旧设计包已经保存了含效果的定位框，仅更新 Unity 不能完全消除这部分偏移。原字体、材质和映射不需要重建。

## 验证范围

410 项 PS 自动化测试通过；14 处真实商店文字通过 Prefab 和预览的几何中心对齐校验。Unity 二进制包通过安装、Schema 1/2/3 导入、图片安全复用、2D 场景及卸载后 Prefab 独立使用验收。安装器 19 项测试及成品 EXE 的 5/5 内置包自检通过。

真实文字测试使用原设计包与源 PSB 像素边界，通过生产导出逻辑生成验证副本；尚未完成 Photoshop 内完整重新导出的实机验收。定位校验不代表阴影、渐变等所有效果均已逐像素还原。
