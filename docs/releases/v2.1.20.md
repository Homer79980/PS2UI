# PS2UI 2.1.20：AI 物体命名与输入保护

2026-10-15。支持 Photoshop 2023 及以上版本。

- AI 优先用普通物体名描述可见主体；明显材质使用常见形容词，减少用途、题材及附属物推测。
- 取图前核对 PSD 文档身份，避免切换文档后取到另一份文件中的同 ID 图层。
- 透明背景必须成功合成到预览；失败时保留原名并提示复核。
- 批量响应核对数量和图层 ID，阻止重复结果覆盖正确名称。
- 更新命名缓存身份，重新识别时使用新规则；保留“分类都是 Img”规则。

## 验证范围

407 项自动化测试通过。保持测试用网关与模型不变，木桌、狗屋、木凳三张实图的单图与批量测试分别得到 `WoodenTable`、`Doghouse`、`WoodenBench`。

实图测试使用导出 PNG 构造的预览并调用生产请求函数。完整 Photoshop 取图、识别、写回流程和其余素材尚未完成实机验收，以上结果不代表整套素材准确率，也不能确定全部历史错名的根因。

## 安装与复测

1. 下载并双击 `PS2UI-Photoshop-2.1.20.ccx`，在 Creative Cloud 中完成安装。
2. 重新打开 Photoshop 面板，确认显示 `2.1.20`。
3. 打开原 PSD，点击“重新识别”，核对结果后再确认写回。

Package 和字体协议保持兼容，引擎端可继续使用当前版本。
