# PS2UI Photoshop v2.1.5

本版本更新 Photoshop 面板的交互与发布稳定性，并同步 Unity 旧版 Assets 路径的依赖引导逻辑。

## 下载

- [PS2UI-Photoshop-2.1.5.ccx](https://github.com/Homer79980/PS2UI/releases/tag/v2.1.5)

## 重点

- 九宫格面板输入和按钮布局修正；
- AI 命名、设置和导出页面的控件间距与遮挡问题修正；
- 同尺寸、同导入契约且像素完全相同的资源在导出包内只保留一个物理 PNG；
- Unity 导入阶段继续使用 MD5/解码像素指纹进行工程资源复用；
- Unity UPM 与旧 Assets 兼容路径的依赖引导保持一致。

## 使用说明

安装后重启 Photoshop，从“插件 -> PS2UI”打开面板，左上角应显示 `v2.1.5`。
