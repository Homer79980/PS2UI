# PS2UI v2.1.15

发布日期：2026-09-17

本次公开更新包含 v2.1.8 之后的面板、导出安全和大文件处理改进。

- 修复导出准备阶段出现 `writeToFile: data cannot be null`、无法开始导出的问题。
- 统一输入框、按钮、文字与背景配色，改善 AI 命名列表及导出弹窗对比度；九宫“确认”和工具“确定”固定在底部居中。
- 加强原稿与已打开文档的保护，恢复导出后的 Photoshop 状态，避免清理时误操作用户文档。
- 优化资源比较，修复部分图层快速导出的定位问题；智能对象采用兼容渲染以保持像素一致。
- 接入实时进度与取消；取消等待当前操作完成并清理暂存文件，保留原有输出。

## 安装

下载 [PS2UI-Photoshop-2.1.15.ccx](https://github.com/Homer79980/PS2UI/releases/download/v2.1.15/PS2UI-Photoshop-2.1.15.ccx)，双击通过 Creative Cloud 安装。保存工作后重启 Photoshop，面板版本应为 v2.1.15。支持 Photoshop 2023（24.0）及以上版本，沿用原插件 ID，可覆盖更新。
