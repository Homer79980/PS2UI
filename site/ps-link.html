PS-LINK / PHONE PREVIEW

把 Photoshop 画面带到手机上。

PS-Link 连接 Photoshop 面板与 Android 手机，支持局域网配对、实时预览、保存同步和快速查看。

获取 PS-Link ↓查看公开仓库 ↗
0.0.1 当前版本LAN 同局域网配对Android 7+ 手机端

DOWNLOAD

先装 Photoshop 插件，再配对手机

电脑和手机连接到同一个 Wi-Fi。Photoshop 插件负责生成配对二维码，Android 端扫码后即可建立连接。

下载 Photoshop 插件下载 Android APK

Android 7.0 / API 24 及以上。首次安装 APK 时，需要允许浏览器或文件管理器安装未知来源应用。

手机扫码下载二维码指向最新 Release，后续版本更新无需更换。
01 / INSTALL

安装

双击安装 Photoshop `.ccx`，再在 Android 手机上安装 APK。打开 Photoshop 面板和手机端应用。

02 / PAIR

配对

点击“开始同步”，用手机扫描面板生成的二维码。两端需要处于同一个局域网。

03 / PREVIEW

预览

选择实时预览或保存同步模式，在手机上快速检查 UI 素材和 Photoshop 当前画面。
