PS-LINK / 0.1.0

把 Photoshop 画面带到手机上。

PS-Link 由 Photoshop 面板、Windows Companion Helper 和 Android 手机端组成。它通过局域网同步当前画板，支持多画板跟随、保存同步和自动预览，画面不会上传云端。

DOWNLOAD

电脑运行一键安装器，手机扫码安装 APK

普通用户优先安装 Windows 一键安装器，它会安装 Companion Helper 并打开 Photoshop 插件包。仅安装 CCX 无法启动同步、生成配对二维码或连接手机。

直接下载 Windows 安装器单独下载 CCX直接下载 Android APK

电脑和手机需要连接同一个可互访的 Wi-Fi。Android 7.0 / API 24 及以上；首次安装 APK 时，需要允许浏览器或文件管理器安装未知来源应用。

扫码直接下载 Android APK当前版本 0.1.0 · Android 7.0 及以上
01 / WINDOWS

安装电脑端

运行一键安装器，完成 Companion Helper 后台服务和 Photoshop CCX 安装。两者必须来自同一版本。

02 / ANDROID

安装手机端

扫描上方二维码直接下载 APK。首次打开时允许相机和局域网相关权限。

03 / PAIR

局域网配对

打开 Photoshop 文档，点击“开始同步”，再用 Android App 扫描面板生成的配对二维码。

04 / PREVIEW

跟随当前画板

在 Photoshop 中切换画板内图层，手机跟随显示当前画板；也可选择保存同步或自动预览。

INTERFACE PREVIEW

从电脑启动，到手机查看当前画板

面板负责取图和配对，Companion Helper 在 Windows 后台中继，Android 端负责显示。
